# Aai Celebration & BS Lawn Catalog — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bilingual (Marathi/English), mobile-first, one-page catalog of the venue's packages, opened by QR code at `catalog.aaicelebration.in`.

**Architecture:** Static Vite + React SPA. All copy, prices, rules, and image URLs live in `src/content.ts` as `{ mr, en }` pairs; a tiny React context picks the language. Sections are plain components composed in `App.tsx`. No backend, no router.

**Tech Stack:** Vite, React (JavaScript/JSX — no TypeScript), Tailwind CSS v4, shadcn/ui (Radix + Embla), lucide-react, Vitest + Testing Library. Hosted on Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-10-30-catalog-design.md` — read it first. Section numbers below (§3, §4…) refer to it.

## Global Constraints

- Project root is this folder (note the parent path contains a trailing space: `Aai Celebration Bs Lawn /` — always quote paths).
- Node ≥ 20.19. JavaScript only (`.js`/`.jsx`, `jsconfig.json` for the `@/` alias, shadcn `tsx: false`). Use the current `create-vite` React template and Tailwind v4 (`@tailwindcss/vite`).
- Allowed runtime deps: react, react-dom, tailwindcss, @tailwindcss/vite, whatever `shadcn add` installs, lucide-react. Dev: vitest, jsdom, @testing-library/react, @testing-library/jest-dom, @testing-library/user-event, qrcode (Task 8 only, via npx). **No** i18n lib, router, state lib, animation lib.
- Every user-visible string comes from `src/content.ts` as a `Text` (`{ mr, en }`). No hard-coded copy in components.
- Default language `mr`; persisted in `localStorage` key `"aai-lang"`; `<html lang>` follows it.
- WhatsApp number `919284325413`. Call numbers `7507504947` (primary) and `9284325413`.
- Prices, inclusions, extras, and the 13 rules are copied **verbatim** from §3. Hall extras contain both `स्वीपर` and `स्पीकर`.
- Colours (sampled from the logo, defined once in `src/index.css` `@theme`): maroon `#7A0811`, maroon-deep `#540305`, gold `#B87A28`, gold-soft `#CB9544`, gold-light `#D1A773`, ivory `#F8F4ED`, paper `#F3ECE2`, ink `#2B1A17`, muted-ink `#6E5A55`. No lawn green — lawn vs hall is shown by the badge only. Light theme only.
- Fonts (Google Fonts, `display=swap`): headings `"Cormorant Garamond", "Tiro Devanagari Marathi", serif` (Latin falls to Cormorant, Devanagari to Tiro); body `"Mukta", sans-serif`.
- Visual rules: no emoji, no gradients except the hero photo overlay, radius 4–6px, no heavy shadows, body text ≥ 16px, tap targets ≥ 44px, motion only via CSS and disabled under `prefers-reduced-motion`.
- First-load JS ≤ ~150 KB gzipped.
- `content/` (original 11 MB posters) is git-ignored; never import from it at runtime.

## Review Focus

1. **`localStorage` blocked** (private mode, in-app QR scanner browsers) → page still renders in Marathi and the toggle works for the session. Test in Task 3.
2. **A string missing one language** → toggling must never show blank text. Content test walks every `Text` in Task 2.
3. **WhatsApp text with Devanagari, `₹`, `&`, spaces** → must be URL-encoded or WhatsApp truncates it. Tests in Task 2 and Task 4.
4. **360px-wide phone with long Marathi words** → no horizontal scroll, and the fixed bottom bar must not cover the footer. Check in Task 7.
5. **Placeholder image fails to load** → card keeps its size (fixed aspect ratio + paper background) and shows alt text. Content test checks every image has bilingual alt (Task 2); aspect boxes in Tasks 4–6.
